# 🔍 Как проверить, сохранен ли пользователь на бэкенде

## 📋 Способ 1: Проверка через Railway логи

### Шаг 1: Откройте Railway
1. Зайдите на https://railway.app
2. Войдите в аккаунт
3. Откройте ваш проект

### Шаг 2: Найдите логи
1. В проекте нажмите на ваш сервис (обычно называется "api" или "backend")
2. Перейдите в раздел **"Deployments"** (Деплои)
3. Выберите последний деплой
4. Или перейдите в раздел **"Logs"** (Логи)

### Шаг 3: Что искать в логах

#### ✅ При успешной регистрации вы увидите:
```
POST /api/users 201
Пользователь сохранен: { id: "...", name: "МИХАИЛ", email: "...", role: "astrologer" }
```

#### ❌ При ошибке вы увидите:
```
POST /api/users 409
Пользователь с таким email уже существует
```

или

```
POST /api/users 400
Не все обязательные поля заполнены
```

### Шаг 4: Проверка загрузки астрологов
Ищите в логах:
```
GET /api/astrologers 200
```

Если видите список астрологов в логах, значит они загружаются.

## 📋 Способ 2: Проверка через API напрямую

### Шаг 1: Найдите URL вашего бэкенда
1. В Railway откройте ваш проект
2. Перейдите в **"Settings"** → **"Networking"**
3. Найдите **"Public Networking"** или **"Custom Domain"**
4. Скопируйте URL (например: `https://astrotoppro-production.up.railway.app`)

### Шаг 2: Проверьте всех пользователей
Откройте в браузере:
```
https://ВАШ_URL_RAILWAY/api/users
```

Например:
```
https://astrotoppro-production.up.railway.app/api/users
```

**Что вы увидите:**
- Если Михаил сохранен, вы увидите его в списке:
```json
[
  {
    "id": "1737123456789",
    "name": "МИХАИЛ",
    "email": "mikhail@example.com",
    "role": "astrologer",
    ...
  }
]
```

### Шаг 3: Проверьте только астрологов
Откройте в браузере:
```
https://ВАШ_URL_RAILWAY/api/astrologers
```

**Что вы увидите:**
- Если Михаил сохранен как астролог, он будет в списке:
```json
[
  {
    "id": "1737123456789",
    "name": "МИХАИЛ",
    "specialty": "Астролог",
    "price": 2000,
    ...
  }
]
```

### Шаг 4: Проверьте бронирования
Откройте в браузере:
```
https://ВАШ_URL_RAILWAY/api/bookings
```

**Что вы увидите:**
- Все заявки на консультации:
```json
[
  {
    "id": "booking-...",
    "specialistId": "1737123456789",
    "specialistName": "МИХАИЛ",
    "clientName": "...",
    "date": "2026-01-21",
    "time": "11:00",
    ...
  }
]
```

## 📋 Способ 3: Проверка через консоль браузера

### Шаг 1: Откройте консоль
1. На сайте astrotop.pro нажмите **F12**
2. Перейдите в вкладку **"Console"** (Консоль)

### Шаг 2: Проверьте загрузку астрологов
В консоли должны быть сообщения:
```
=== ИНИЦИАЛИЗАЦИЯ СПЕЦИАЛИСТОВ ===
Загрузка астрологов с бэкенда...
Астрологи с бэкенда: [...]
Итоговый список специалистов: [...]
```

**Если видите Михаила в списке** - он сохранен и загружается!

### Шаг 3: Проверьте загрузку консультаций
В кабинете астролога в консоли должны быть:
```
Загрузка бронирований для астролога (user.id): 1737123456789
Бронирования загружены: [...]
Консультации установлены: [...]
```

## 📋 Способ 4: Проверка через Network (Сеть)

### Шаг 1: Откройте Network
1. На сайте astrotop.pro нажмите **F12**
2. Перейдите в вкладку **"Network"** (Сеть)
3. Обновите страницу (F5)

### Шаг 2: Найдите запросы к API
Ищите запросы:
- `GET /api/astrologers` - загрузка астрологов
- `GET /api/bookings` - загрузка бронирований
- `POST /api/users` - регистрация пользователя

### Шаг 3: Проверьте ответы
1. Кликните на запрос `GET /api/astrologers`
2. Перейдите в вкладку **"Response"** (Ответ)
3. Проверьте, есть ли Михаил в списке

## 🔧 Что делать, если Михаил НЕ сохранен

### Проблема 1: Ошибка при регистрации
**Решение:**
1. Проверьте логи Railway на ошибки
2. Убедитесь, что все поля заполнены
3. Проверьте, что email уникален

### Проблема 2: Бэкенд недоступен
**Решение:**
1. Проверьте, что Railway проект запущен
2. Проверьте URL в `VITE_API_URL` в Vercel
3. Проверьте, что бэкенд отвечает (откройте URL в браузере)

### Проблема 3: Михаил сохранен, но не появляется в списке
**Решение:**
1. Обновите страницу `/specialists` (F5)
2. Подождите 30 секунд (автообновление)
3. Проверьте консоль браузера на ошибки

## ✅ Быстрая проверка

### Чек-лист:
- [ ] Railway проект запущен
- [ ] URL бэкенда правильный в Vercel (`VITE_API_URL`)
- [ ] В логах Railway нет ошибок
- [ ] API `/api/users` возвращает список пользователей
- [ ] API `/api/astrologers` возвращает список астрологов
- [ ] В консоли браузера нет ошибок
- [ ] Михаил виден в списке на `/specialists`

---

## 🆘 Если ничего не помогает

1. **Проверьте переменные окружения:**
   - В Vercel: `VITE_API_URL` должен быть URL Railway
   - В Railway: проект должен быть запущен

2. **Проверьте логи Railway:**
   - Есть ли ошибки при запуске?
   - Есть ли ошибки при запросах?

3. **Попробуйте зарегистрировать Михаила заново:**
   - Убедитесь, что email уникален
   - Проверьте, что роль выбрана "Астролог"

4. **Проверьте консоль браузера:**
   - Откройте F12 → Console
   - Ищите ошибки красным цветом
