# 🔧 Диагностика: Бэкенд не работает

## ❌ Проблема:
- Не могу опубликовать новость
- URL бэкенда не работает (not found)

---

## 🔍 Шаг 1: Проверка Railway (БЭКЕНД)

### 1.1. Проверьте статус деплоя

1. Зайдите на https://railway.app
2. Откройте ваш проект
3. Вкладка **"Deployments"** (Деплои)
4. Посмотрите на последний деплой:
   - ✅ **Зеленая галочка** = работает
   - ❌ **Красный крестик** = ошибка
   - 🟡 **Желтый кружок** = идет сборка

**Если ошибка → смотрите логи (см. ниже)**

---

### 1.2. Проверьте настройки проекта

1. В Railway откройте ваш проект
2. **Settings → Build & Deploy Settings**
3. Проверьте:

   **Root Directory:**
   - Должно быть: `server`
   - ❌ Если пусто или другое → исправьте!

   **Start Command:**
   - Должно быть: `npm start`
   - ❌ Если пусто или другое → исправьте!

4. **Сохраните** изменения
5. Railway автоматически перезапустит проект

---

### 1.3. Проверьте логи (если есть ошибки)

1. В Railway: **Deployments → последний деплой**
2. Нажмите **"View Logs"** (Просмотр логов)
3. Прокрутите вниз до конца
4. Ищите ошибки (красный текст)

**Частые ошибки:**
- `Cannot find module` → не установлены зависимости
- `EADDRINUSE` → порт занят (нормально для Railway)
- `ENOENT` → файл не найден (проверьте Root Directory)

**Что делать с ошибками:**
- Скопируйте текст ошибки
- Проверьте, что Root Directory = `server`
- Проверьте, что Start Command = `npm start`

---

### 1.4. Проверьте URL бэкенда

1. В Railway: **Settings → Networking**
2. Найдите раздел **"Public Networking"**
3. Должен быть URL: `astrotoppro-production.up.railway.app`

**Если URL нет:**
- Нажмите **"Generate Domain"**
- Подождите несколько секунд

**Если URL есть:**
- Скопируйте его
- Откройте в браузере: `https://astrotoppro-production.up.railway.app/api/news`
- Должен вернуться JSON: `[]` (пустой массив)

**Если "not found" или ошибка:**
- Бэкенд не запущен или неправильно настроен
- Проверьте логи (см. выше)
- Проверьте настройки (Root Directory, Start Command)

---

## 🔍 Шаг 2: Проверка Vercel (ФРОНТЕНД)

### 2.1. Проверьте переменные окружения

1. Зайдите на https://vercel.com/dashboard
2. Откройте проект `astrotop.pro`
3. **Settings → Environment Variables**
4. Должны быть 2 переменные:

   **Переменная 1:**
   - Name: `VITE_API_URL`
   - Value: `https://astrotoppro-production.up.railway.app`
   - Environment: ✅ Production ✅ Preview ✅ Development

   **Переменная 2:**
   - Name: `VITE_SOCKET_URL`
   - Value: `https://astrotoppro-production.up.railway.app`
   - Environment: ✅ Production ✅ Preview ✅ Development

**Если переменных нет или неправильные:**
- Добавьте/исправьте их
- **ВАЖНО:** После добавления нужно пересобрать проект!

---

### 2.2. Пересоберите проект (ОБЯЗАТЕЛЬНО!)

**После добавления/изменения переменных окружения:**

1. В Vercel: **Deployments** (Деплои)
2. Найдите последний деплой
3. Нажмите **"..."** (три точки)
4. Выберите **"Redeploy"** (Пересобрать)
5. Подождите 1-3 минуты
6. Дождитесь завершения (зеленая галочка)

**⚠️ БЕЗ ПЕРЕСБОРКИ переменные НЕ применятся!**
