## 🚀 Инструкция: Подключение ЮKassa (рекомендуется для России)

### Шаг 1: Регистрация в ЮKassa

1. Зайдите на https://yookassa.ru
2. Зарегистрируйтесь или войдите
3. Создайте магазин (если еще нет)
4. Получите:
   - **shopId** (ID магазина)
   - **secretKey** (секретный ключ)

---

### Шаг 2: Установка библиотеки

В терминале выполните:

```bash
npm install @yookassa/sdk
```

---

### Шаг 3: Настройка на бэкенде

1. Откройте `server/index.js`
2. Добавьте в начало файла:

```javascript
const { YooCheckout } = require('@yookassa/sdk')
const yooCheckout = new YooCheckout({
  shopId: process.env.YOOKASSA_SHOP_ID,
  secretKey: process.env.YOOKASSA_SECRET_KEY
})
```

3. Добавьте API endpoint для создания платежа:

```javascript
// Создание платежа через ЮKassa
app.post('/api/payments/create', async (req, res) => {
  try {
    const { amount, currency, description, consultationId } = req.body
    
    const payment = await yooCheckout.createPayment({
      amount: {
        value: amount.toFixed(2),
        currency: currency === 'RUB' ? 'RUB' : 'USD'
      },
      confirmation: {
        type: 'redirect',
        return_url: `${process.env.FRONTEND_URL}/payment/success`
      },
      description: description || `Оплата консультации #${consultationId}`,
      metadata: {
        consultationId: consultationId
      }
    })
    
    res.json({
      id: payment.id,
      confirmationUrl: payment.confirmation.confirmation_url
    })
  } catch (error) {
    console.error('Ошибка создания платежа:', error)
    res.status(500).json({ error: 'Ошибка создания платежа' })
  }
})

// Проверка статуса платежа
app.get('/api/payments/:paymentId', async (req, res) => {
  try {
    const payment = await yooCheckout.getPayment(req.params.paymentId)
    res.json({
      id: payment.id,
      status: payment.status,
      paid: payment.paid
    })
  } catch (error) {
    console.error('Ошибка проверки платежа:', error)
    res.status(500).json({ error: 'Ошибка проверки платежа' })
  }
})

// Webhook для уведомлений от ЮKassa
app.post('/api/payments/webhook', express.raw({ type: 'application/json' }), async (req, res) => {
  try {
    const event = req.body
    // Обработка события платежа
    if (event.event === 'payment.succeeded') {
      const consultationId = event.object.metadata.consultationId
      // Обновить статус бронирования
      console.log(`Платеж успешен для консультации ${consultationId}`)
    }
    res.status(200).send('OK')
  } catch (error) {
    console.error('Ошибка обработки webhook:', error)
    res.status(500).send('Error')
  }
})
```

### Шаг 4: Добавьте переменные окружения в Railway

1. Зайдите на https://railway.app
2. Откройте ваш проект
3. **Settings → Variables**
4. Добавьте:
   - **Name:** `YOOKASSA_SHOP_ID`
   - **Value:** ваш shopId из ЮKassa
   
   - **Name:** `YOOKASSA_SECRET_KEY`
   - **Value:** ваш secretKey из ЮKassa

5. Сохраните

---

### Шаг 5: Обновите фронтенд

Откройте `src/contexts/PaymentContext.jsx` и замените функцию `processPayment`:

```javascript
const processPayment = async (paymentData) => {
  try {
    const API_BASE_URL = import.meta.env.VITE_API_URL || ''
    
    // Создаем платеж через бэкенд
    const response = await fetch(`${API_BASE_URL}/api/payments/create`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        amount: paymentData.amount,
        currency: paymentData.currency,
        description: `Оплата консультации ${paymentData.consultationId}`,
        consultationId: paymentData.consultationId
      })
    })
    
    if (!response.ok) {
      throw new Error('Ошибка создания платежа')
    }
    
    const payment = await response.json()
    
    // Перенаправляем на страницу оплаты ЮKassa
    window.location.href = payment.confirmationUrl
    
    return {
      success: true,
      paymentId: payment.id
    }
  } catch (error) {
    console.error('Ошибка платежа:', error)
    return {
      success: false,
      error: error.message
    }
  }
}
```

## 🚀 Инструкция: Подключение Stripe (для международных платежей)

### Шаг 1: Регистрация в Stripe

1. Зайдите на https://stripe.com
2. Зарегистрируйтесь
3. Получите:
   - **Publishable Key** (публичный ключ)
   - **Secret Key** (секретный ключ)

---

### Шаг 2: Установка библиотеки

```bash
npm install stripe
```

---

### Шаг 3: Настройка на бэкенде

1. Откройте `server/index.js`
2. Добавьте:

```javascript
const stripe = require('stripe')(process.env.STRIPE_SECRET_KEY)

// Создание платежа
app.post('/api/payments/create', async (req, res) => {
  try {
    const { amount, currency, consultationId } = req.body
    
    const session = await stripe.checkout.sessions.create({
      payment_method_types: ['card'],
      line_items: [{
        price_data: {
          currency: currency.toLowerCase(),
          product_data: {
            name: `Консультация #${consultationId}`,
          },
          unit_amount: Math.round(amount * 100), // Stripe использует центы
        },
        quantity: 1,
      }],
      mode: 'payment',
      success_url: `${process.env.FRONTEND_URL}/payment/success?session_id={CHECKOUT_SESSION_ID}`,
      cancel_url: `${process.env.FRONTEND_URL}/payment/cancel`,
      metadata: {
        consultationId: consultationId
      }
    })
    
    res.json({
      sessionId: session.id,
      url: session.url
    })
  } catch (error) {
    console.error('Ошибка создания платежа:', error)
    res.status(500).json({ error: error.message })
  }
})
```

## 🔒 Безопасность:

1. **Никогда не храните секретные ключи в коде!**
   - Используйте переменные окружения
   - Добавляйте их только в Railway/Vercel

2. **Проверяйте платежи на бэкенде:**
   - Не доверяйте данным с фронтенда
   - Всегда проверяйте статус платежа на сервере

3. **Используйте HTTPS:**
   - Все запросы должны идти через HTTPS
   - Vercel и Railway уже используют HTTPS
