## 📝 Пошаговый план действий

### Шаг 1: Деплой бэкенда (если еще не сделано)

**Рекомендуется Render.com (бесплатно):**

1. Зайдите на https://render.com
2. Зарегистрируйтесь (можно через GitHub)
3. Нажмите "New" → "Web Service"
4. Подключите ваш GitHub репозиторий
5. Заполните:
   - **Name:** `astrotop-backend` (любое имя)
   - **Root Directory:** `server`
   - **Build Command:** `npm install`
   - **Start Command:** `node index.js`
6. Нажмите "Create Web Service"
7. Подождите деплоя (5-10 минут)
8. Скопируйте URL (например: `astrotop-backend.onrender.com`)

---

### Шаг 2: Настройка переменных окружения

#### На Render.com (бэкенд):

1. В Dashboard откройте ваш сервис
2. Перейдите на вкладку "Environment"
3. Добавьте переменную:
   - **Key:** `FRONTEND_URL`
   - **Value:** `https://astrotop.pro` (или ваш Vercel URL)
4. Нажмите "Save Changes"
5. Сервис перезапустится

#### На Vercel (фронтенд):

1. Зайдите на https://vercel.com
2. Выберите проект `astrotop` (или как называется)
3. Settings → Environment Variables
4. Добавьте две переменные:

   **Переменная 1:**
   - Key: `VITE_API_URL`
   - Value: `https://your-backend-url.onrender.com` (URL из шага 1)
   - Environments: Production, Preview, Development (выберите все)

   **Переменная 2:**
   - Key: `VITE_SOCKET_URL`
   - Value: `https://your-backend-url.onrender.com` (тот же URL)
   - Environments: Production, Preview, Development (выберите все)

5. Нажмите "Save"
6. **ВАЖНО:** Перейдите на вкладку "Deployments"
7. Нажмите "..." на последнем деплое → "Redeploy"
8. Или сделайте `git push` чтобы передеплоить

---

### Шаг 3: Проверка работы

1. **Проверьте бэкенд:**
   ```
   https://your-backend-url.onrender.com/api/health
   ```
   Должно показать: `{"status":"ok"}`

2. **Проверьте фронтенд:**
   - Откройте `astrotop.pro`
   - Откройте консоль (F12 → Console)
   - Не должно быть ошибок подключения

3. **Протестируйте функции:**
   - Регистрация
   - Вход
   - Загрузка фото профиля
   - Просмотр товаров

## ⚠️ Частые проблемы и решения

### Проблема 1: CORS ошибки
**Решение:** Проверьте `FRONTEND_URL` на бэкенде - должен точно совпадать с URL фронтенда

### Проблема 2: Бэкенд не отвечает
**Решение:** 
- Проверьте логи на Render.com/Railway
- Убедитесь, что команда `node index.js` правильная
- Проверьте, что все зависимости установлены

### Проблема 3: Переменные окружения не работают
**Решение:**
- После добавления переменных на Vercel - обязательно сделайте Redeploy!
- Переменные применяются только при новом деплое

### Проблема 4: Видеочат не работает
**Решение:**
- Убедитесь, что `VITE_SOCKET_URL` правильно настроен
- Проверьте, что Socket.IO работает на бэкенде
- Проверьте консоль браузера на ошибки
