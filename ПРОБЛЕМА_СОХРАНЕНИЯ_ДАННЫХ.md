# ⚠️ ПРОБЛЕМА: Данные не сохраняются на Railway

## 🔴 Проблема

**На Railway файлы в папке `data` НЕ сохраняются между деплоями!**

Railway использует **эфемерную файловую систему** - это значит, что при каждом деплое все файлы удаляются и создаются заново.

**Результат:**
- ❌ Пользователи регистрируются, но данные не сохраняются
- ❌ Бронирования создаются, но исчезают после деплоя
- ❌ Новости публикуются, но пропадают

---

## ✅ РЕШЕНИЕ: Использовать Railway Volume

### Вариант 1: Railway Volume (Рекомендуется)

#### Шаг 1: Создайте Volume в Railway

1. Откройте Railway → ваш проект
2. Нажмите **"New"** → **"Volume"**
3. Назовите volume: `data-storage`
4. Выберите размер: `1 GB` (достаточно)
5. Нажмите **"Add"**

#### Шаг 2: Подключите Volume к сервису

1. Откройте ваш сервис (backend)
2. Перейдите в **"Settings"** → **"Volumes"**
3. Нажмите **"Add Volume"**
4. Выберите volume: `data-storage`
5. **Mount Path:** `/app/data` ⬅️ **ВАЖНО!**
6. Нажмите **"Add"**

#### Шаг 3: Обновите код для использования Volume

Нужно изменить путь к папке `data` в `server/index.js`:

**Было:**
```javascript
const USERS_DIR = path.join(__dirname, 'data')
```

**Должно быть:**
```javascript
// Используем Railway Volume, если он доступен, иначе локальную папку
const DATA_DIR = process.env.RAILWAY_VOLUME_MOUNT_PATH || path.join(__dirname, 'data')
const USERS_DIR = path.join(DATA_DIR, 'users')
```

---

## ✅ РЕШЕНИЕ: Использовать переменную окружения для пути

### Более простое решение (без Volume)

Измените код, чтобы использовать переменную окружения:

```javascript
// Используем переменную окружения или локальную папку
const DATA_BASE_DIR = process.env.DATA_DIR || path.join(__dirname, 'data')
const USERS_DIR = path.join(DATA_BASE_DIR, 'users')
const USERS_FILE = path.join(USERS_DIR, 'users.json')
```

Но это не решит проблему полностью - данные все равно будут теряться при деплое.

---

## ✅ РЕШЕНИЕ: Использовать базу данных (Лучший вариант)

### PostgreSQL на Railway

1. В Railway нажмите **"New"** → **"Database"** → **"Add PostgreSQL"**
2. Подождите, пока база создастся
3. Скопируйте **DATABASE_URL** из переменных окружения
4. Установите библиотеку: `npm install pg`
5. Обновите код для работы с PostgreSQL

**Это самое надежное решение!**

## 🔍 Как проверить, сохраняются ли данные

### Способ 1: Проверка через API

Откройте в браузере:
```
https://astrotoppro-production.up.railway.app/api/users
```

**Если видите пустой массив `[]`** - данные не сохраняются.

**Если видите пользователей** - данные сохраняются.

### Способ 2: Проверка через логи

В Railway → **HTTP Logs** ищите:
```
✅ ПОЛЬЗОВАТЕЛЬ ЗАРЕГИСТРИРОВАН: ...
📊 Всего пользователей: 1
```

Затем проверьте через API - если пользователей нет, значит данные не сохраняются.

## 🚨 ВАЖНО: VITE_API_URL правильный!

**`VITE_API_URL` должен указывать на Railway, НЕ на astrotop.pro!**

✅ **Правильно:**
```
VITE_API_URL=https://astrotoppro-production.up.railway.app
```

❌ **Неправильно:**
```
VITE_API_URL=https://astrotop.pro
```

**Почему?**
- `astrotop.pro` - это фронтенд (Vercel)
- `astrotoppro-production.up.railway.app` - это бэкенд (Railway)
