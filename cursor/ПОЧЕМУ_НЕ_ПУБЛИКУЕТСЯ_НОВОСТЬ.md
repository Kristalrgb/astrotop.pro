# ❌ Почему не публикуется новость?

## 🔍 Проблема:

**Новость сохраняется локально в браузере, но не публикуется на сервере.**

Вы видите сообщение:
> "Сервер недоступен. Новость сохранена локально. Синхронизация произойдет автоматически после восстановления связи с сервером."

---

## 🎯 Причина:

**Бэкенд (сервер) не настроен или не работает.**

Есть две возможные причины:

### 1. ❌ Бэкенд не задеплоен на Railway/Render
- Бэкенд не запущен в интернете
- Нет URL для подключения

### 2. ❌ Переменные окружения не настроены в Vercel
- `VITE_API_URL` не добавлена
- Или добавлена неправильно

---

## ✅ Что происходит сейчас:

1. ✅ Вы создаете новость
2. ✅ Новость сохраняется в **вашем браузере** (localStorage)
3. ❌ Новость **НЕ отправляется на сервер**
4. ❌ Другие пользователи **НЕ видят** вашу новость
5. ✅ Вы видите новость только на **своем компьютере**

---

## 🚀 Решение (2 шага):

### Шаг 1: Настроить бэкенд на Railway (15 минут)

1. **Зайдите на https://railway.app**
2. **Войдите через GitHub**
3. **New Project → Deploy from GitHub repo**
4. **Выберите ваш репозиторий**
5. **В настройках проекта:**
   - Root Directory: `server`
   - Start Command: `npm start`
6. **Settings → Networking → Generate Domain**
7. **Скопируйте URL** (например: `https://xxx.up.railway.app`)

**Подробная инструкция:** См. `КАК_СДЕЛАТЬ_БЭКЕНД.md`

---

### Шаг 2: Добавить переменные окружения в Vercel (5 минут)

1. **Зайдите на https://vercel.com/dashboard**
2. **Выберите проект → Settings → Environment Variables**
3. **Добавьте 2 переменные:**

   **Переменная 1:**
   - Name: `VITE_API_URL`
   - Value: `https://xxx.up.railway.app` (URL из шага 1)
   - Environment: ✅ Production ✅ Preview ✅ Development
   
   **Переменная 2:**
   - Name: `VITE_SOCKET_URL`
   - Value: `https://xxx.up.railway.app` (тот же URL)
   - Environment: ✅ Production ✅ Preview ✅ Development

4. **Сохраните**
5. **Deployments → последний деплой → "..." → Redeploy**

**Подробная инструкция:** См. `ОБНОВЛЕНИЕ_ВЕРСЕЛЬ.md`

---

## ✅ После настройки:

1. ✅ Новость отправляется на сервер
2. ✅ Все пользователи видят вашу новость
3. ✅ Новости сохраняются на сервере
4. ✅ Новости не теряются при очистке браузера

---

## 🔄 Что произойдет с локальными новостями:

После настройки бэкенда:

1. ✅ Локальные новости **автоматически синхронизируются** с сервером
2. ✅ Все новости, которые вы создали локально, появятся на сервере
3. ✅ Не нужно создавать их заново

**Синхронизация происходит автоматически каждые 30 секунд.**

---

## 📋 Быстрая проверка:

### Проверка 1: Есть ли бэкенд на Railway?
- Зайдите на https://railway.app
- Если нет проекта → нужно создать (см. Шаг 1)
- Если есть проект → скопируйте URL

### Проверка 2: Настроены ли переменные в Vercel?
- Зайдите на https://vercel.com/dashboard
- Settings → Environment Variables
- Должны быть 2 переменные: `VITE_API_URL` и `VITE_SOCKET_URL`
- Если нет → нужно добавить (см. Шаг 2)

### Проверка 3: Работает ли бэкенд?
- Откройте в браузере: `https://ваш-бэкенд.railway.app/api/news`
- Должен вернуться JSON: `[]` (пустой массив)
- Если ошибка → бэкенд не работает, проверьте Railway

---

## 💡 Итого:

**Проблема:** Бэкенд не настроен

**Решение:** 
1. Настроить бэкенд на Railway (15 минут)
2. Добавить переменные окружения в Vercel (5 минут)

**После этого:** Новости будут публиковаться нормально! 🎉
