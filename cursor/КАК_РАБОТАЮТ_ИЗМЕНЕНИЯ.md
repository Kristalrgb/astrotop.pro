# 🔄 Как изменения появляются в разных местах

## 📍 Три места, где работает ваш сайт:

1. **localhost:3000** - Локальная разработка (ваш компьютер)
2. **astrotop.pro** - Продакшн домен (интернет)
3. **astrotop-pro.vercel.app** - Vercel URL (тот же продакшн, другой адрес)

---

## 🖥️ 1. localhost:3000 (Локальная разработка)

### Как запустить:
```bash
npm run dev
```

### Когда изменения появляются:
- **Мгновенно** (Hot Module Replacement)
- Вы сохраняете файл (Ctrl+S) → изменение видно сразу
- Без перезагрузки страницы (в большинстве случаев)
- Без перезапуска сервера

### Особенности:
- ✅ Работает только на вашем компьютере
- ✅ Только вы видите изменения
- ✅ Подключается к локальному бэкенду (localhost:5000)
- ✅ Идеально для разработки и тестирования

### Структура:
```
Ваш компьютер
└── Vite Dev Server (порт 3000)
    ├── Frontend (React)
    └── Proxy → Backend (localhost:5000)
```

---

## 🌐 2. astrotop-pro.vercel.app (Vercel URL)

### Как изменения появляются:

#### Вариант A: Автоматически (через GitHub)
```
1. Вы меняете код в Cursor
   ↓
2. git add . && git commit -m "..." && git push
   ↓
3. GitHub получает изменения
   ↓
4. Vercel автоматически обнаруживает изменения (5-10 сек)
   ↓
5. Vercel запускает сборку (npm run build) - 30-90 сек
   ↓
6. Vercel деплоит новую версию - 10-30 сек
   ↓
7. Изменения появляются на astrotop-pro.vercel.app
   ⏱️ Общее время: 1-3 минуты
```

#### Вариант B: Вручную (через Vercel CLI)
```bash
npm run deploy
# или
vercel --prod
```
⏱️ Время: 1-3 минуты

### Особенности:
- ✅ Доступен в интернете (любой может зайти)
- ✅ Автоматическая сборка при каждом push
- ✅ CDN (быстрая загрузка по всему миру)
- ✅ HTTPS включен автоматически

---

## 🌍 3. astrotop.pro (Продакшн домен)

### Как изменения появляются:

```
astrotop.pro = это просто другое имя для astrotop-pro.vercel.app
```

### Настройка:
1. В Vercel Dashboard → Settings → Domains
2. Добавлен домен `astrotop.pro`
3. DNS записи настроены у регистратора домена

### Процесс обновления:
```
Вы делаете изменения
   ↓
git push на GitHub
   ↓
Vercel собирает и деплоит
   ↓
Изменения появляются ОДНОВРЕМЕННО на:
   ├── astrotop-pro.vercel.app
   └── astrotop.pro (это один и тот же сайт!)
```

⏱️ Время: **1-3 минуты** (как и для Vercel URL)

## 🔄 Полный цикл разработки

### Шаг 1: Разработка (localhost:3000)
```bash
npm run dev
# Откройте http://localhost:3000
# Делайте изменения, сохраняйте (Ctrl+S)
# Изменения видны сразу!
```

### Шаг 2: Тестирование (опционально)
```bash
npm run build
npm run preview
# Проверьте, что всё работает
```

### Шаг 3: Отправка на GitHub
```bash
git add .
git commit -m "Описание изменений"
git push
```

### Шаг 4: Автоматический деплой (1-3 минуты)
```
Vercel автоматически:
1. Обнаруживает изменения
2. Собирает проект (npm run build)
3. Деплоит новую версию
4. Обновляет оба домена одновременно:
   - astrotop-pro.vercel.app
   - astrotop.pro
```

### Шаг 5: Проверка
- Откройте https://astrotop.pro
- Или https://astrotop-pro.vercel.app
- Оба показывают одну и ту же версию!

## 🎯 Важные моменты

### ✅ Что происходит одновременно:
- `astrotop-pro.vercel.app` и `astrotop.pro` - это **один и тот же сайт**
- Они обновляются **одновременно**
- Это просто разные имена для одного деплоя

### ⚠️ Отличие от localhost:
- **localhost:3000** - это ваш компьютер, изменения мгновенные
- **astrotop.pro** - это интернет, изменения через 1-3 минуты после git push

### 🔍 Как проверить статус деплоя:
1. Откройте https://vercel.com/dashboard
2. Выберите проект
3. Вкладка "Deployments"
4. Смотрите статус последнего деплоя:
   - ✅ Ready - готово, изменения применены
   - 🟡 Building - идет сборка
   - ❌ Error - ошибка, нужно посмотреть логи

## 💡 Пример работы

### Сценарий: Вы изменили кнопку на главной странице

1. **Локально (localhost:3000):**
   ```
   Вы редактируете src/pages/Home.jsx
   → Сохраняете (Ctrl+S)
   → Изменение видно СРАЗУ в браузере
   ⏱️ Время: 0 секунд
   ```

2. **На GitHub:**
   ```bash
   git add .
   git commit -m "Изменил кнопку на главной"
   git push
   ⏱️ Время: 5-10 секунд
   ```

3. **На Vercel (автоматически):**
   ```
   Vercel обнаружил изменения
   → Запустил сборку (npm run build)
   → Задеплоил новую версию
   ⏱️ Время: 1-3 минуты
   ```

4. **Результат:**
   ```
   Открываете https://astrotop.pro
   → Видите новую кнопку!
   
   Открываете https://astrotop-pro.vercel.app
   → Тоже видите новую кнопку!
   
   (Это один и тот же сайт)
   ```
