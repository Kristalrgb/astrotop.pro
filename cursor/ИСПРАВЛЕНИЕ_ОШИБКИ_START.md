# 🔧 Исправление ошибки "Missing script: start"

## ❌ Проблема
```
npm error Missing script: "start"
```

## 🔍 Причина
Railway не находит `package.json` в папке `server`, потому что:
- Либо **Root Directory** не установлен на `server`
- Либо Railway ищет `package.json` в корне проекта

## ✅ Решение

### Шаг 1: Проверьте Root Directory в Railway

1. Откройте проект **"zesty-mindfulness"** в Railway
2. Откройте сервис **"astrotop-backend"**
3. Перейдите в **"Settings"** (вкладка вверху)
4. Найдите раздел **"Build & Deploy Settings"**
5. Проверьте поле **"Root Directory"**:
   - Должно быть: `server` ⬅️ **ВАЖНО!**
   - Если пусто или другое значение - измените на `server`
6. Нажмите **"Save"**

### Шаг 2: Проверьте Start Command

В том же разделе **"Build & Deploy Settings"**:
- **Start Command:** должно быть `npm start`
- Или можно оставить пустым (Railway автоматически найдет скрипт)

### Шаг 3: Редеплой

1. После сохранения настроек Railway автоматически перезапустит сервис
2. Или нажмите **"Redeploy"** вручную
3. Дождитесь завершения деплоя

---

## 🔍 Если ошибка осталась

### Вариант 1: Укажите полный путь к команде

В **Start Command** укажите:
```
cd server && npm start
```

### Вариант 2: Используйте node напрямую

В **Start Command** укажите:
```
node server/index.js
```

---

## ✅ Проверка

После исправления:
1. Откройте **"Deploy Logs"**
2. Должно быть: `Сервер запущен на порту XXXX` ✅
3. Статус должен стать **"Online"** (зеленый)

---

## 📝 Примечание

Если у вас несколько проектов на Railway, возможно они создавались в разное время с разными настройками. Оставьте один рабочий проект (например, "zesty-mindfulness" с PostgreSQL), остальные можно удалить.
