## 🔄 Как восстановить версию декабря

### Вариант 1: Восстановить локально (для тестирования)

```bash
# Посмотреть все бэкапы
git tag -l "backup-*"

# Восстановить версию декабря
git checkout backup-december-2025

# Вернуться к текущей версии
git checkout main
```

### Вариант 2: Восстановить на сайте (полный откат)

```bash
# Откатить код к версии декабря
git reset --hard backup-december-2025

# Отправить в GitHub
git push origin main --force

# Vercel автоматически задеплоит эту версию (1-3 минуты)
```

## 📋 Как создать новый бэкап

### Быстрый способ:
```bash
# Создать бэкап с текущей датой
git tag backup-$(Get-Date -Format "yyyyMMdd-HHmmss")

# Отправить в GitHub
git push origin --tags
```

### С описанием:
```bash
# Создать бэкап с описанием
git tag backup-stable-v1 -m "Стабильная версия с исправлениями"

# Отправить в GitHub
git push origin --tags
```

## 🔍 Как посмотреть все бэкапы

```bash
# Все бэкапы
git tag -l "backup-*"

# Информация о конкретном бэкапе
git show backup-december-2025

# История коммитов до бэкапа
git log backup-december-2025 --oneline -10
```

---

## ⚠️ Важно

1. **Бэкапы хранятся в Git** - они не занимают место на диске
2. **Теги отправлены в GitHub** - они сохранены в облаке
3. **Восстановление через force push** - это перезапишет текущую версию
4. **Vercel автоматически деплоит** - после push сайт обновится через 1-3 минуты

## 🎯 Примеры использования

### Восстановить версию декабря на сайте:
```bash
git reset --hard backup-december-2025
git push origin main --force
```

### Создать новый бэкап перед изменениями:
```bash
git tag backup-before-changes-$(Get-Date -Format "yyyyMMdd-HHmmss")
git push origin --tags
```

### Посмотреть, что было в версии декабря:
```bash
git checkout backup-december-2025
# Посмотреть файлы, протестировать
git checkout main  # Вернуться обратно
```

## 📞 Если что-то пошло не так

Если восстановление не сработало:
1. Проверь, что тег существует: `git tag -l "backup-*"`
2. Проверь статус: `git status`
3. Попробуй снова: `git reset --hard backup-december-2025`
4. Если не помогает - напиши, помогу исправить
