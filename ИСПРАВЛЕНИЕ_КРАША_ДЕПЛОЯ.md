## 📋 Что делать СЕЙЧАС

### Шаг 1: Проверьте логи в Railway

1. Откройте Railway → ваш проект "astrotop.pro"
2. Перейдите в **"Logs"** (вкладка вверху)
3. Посмотрите последние логи - там должна быть ошибка

**Что искать:**
- `❌ Ошибка при создании хранилища...`
- `❌ Необработанная ошибка:`
- `Error: EACCES` (нет прав на запись)
- `Error: ENOSPC` (нет места)

### Шаг 2: Проверьте настройки Railway

1. Откройте **Settings** → **Variables**
2. Убедитесь, что есть:
   - `PORT` (Railway устанавливает автоматически)
   - `NODE_ENV=production` (опционально)

### Шаг 3: Проверьте Root Directory

1. Откройте **Settings** → **Build & Deploy Settings**
2. Убедитесь, что **Root Directory:** `server` ⬅️ **ВАЖНО!**

### Шаг 4: Сделайте редеплой

1. В Railway нажмите **"Redeploy"**
2. Следите за логами в реальном времени
3. Если видите ошибку - скопируйте её и отправьте мне

## 🔍 Типичные причины краша

### 1. Неправильный Root Directory

**Проблема:** Railway не может найти `package.json`

**Решение:** 
- Settings → Build & Deploy Settings
- Root Directory: `server`

### 2. Ошибка при создании папок

**Проблема:** Нет прав на запись в файловую систему

**Решение:** 
- Используйте Railway Volume (см. `КАК_СОЗДАТЬ_VOLUME_RAILWAY.md`)
- Или используйте PostgreSQL

### 3. Отсутствующие зависимости

**Проблема:** Не установлены npm пакеты

**Решение:**
- Проверьте, что в `server/package.json` все зависимости указаны
- Railway должен автоматически выполнить `npm install`

### 4. Ошибка в коде

**Проблема:** Синтаксическая ошибка или ошибка выполнения

**Решение:**
- Проверьте логи - там будет указана строка с ошибкой
- Исправьте ошибку и сделайте коммит
