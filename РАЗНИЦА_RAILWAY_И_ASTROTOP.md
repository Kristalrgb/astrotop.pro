# 🔍 Разница между Railway и astrotop.pro

## ❓ Ваш вопрос:

> "У меня сайт на Railway и на astrotop.pro? Нужно вносить исправления там и там?"

---

## ✅ Ответ: НЕТ, это РАЗНЫЕ вещи!

### 🎯 Railway = БЭКЕНД (сервер)
- **Что это:** Серверная часть (бэкенд)
- **Где:** https://railway.app
- **URL:** `https://xxx.up.railway.app` (например: `https://astrotop-backend.up.railway.app`)
- **Что делает:** Сохраняет новости, обрабатывает API запросы
- **Для пользователей:** НЕ виден напрямую (работает "в фоне")

### 🌐 astrotop.pro = ФРОНТЕНД (сайт)
- **Что это:** Ваш сайт (то, что видят пользователи)
- **Где:** https://vercel.com (хостится на Vercel)
- **URL:** `https://astrotop.pro` (ваш домен)
- **Что делает:** Показывает страницы, интерфейс
- **Для пользователей:** Виден напрямую (это ваш сайт!)

## 🔧 Где что настраивать:

### 1️⃣ Railway (БЭКЕНД) - настройки сервера

**Что настраивать:**
- ✅ Root Directory: `server`
- ✅ Start Command: `npm start`
- ✅ Переменные окружения (если нужны)
- ✅ URL бэкенда (получить после деплоя)

**Где:** https://railway.app → ваш проект → Settings

**Зачем:** Чтобы сервер работал и сохранял новости

---

### 2️⃣ Vercel (ФРОНТЕНД) - настройки сайта

**Что настраивать:**
- ✅ Переменные окружения:
  - `VITE_API_URL` = URL бэкенда из Railway
  - `VITE_SOCKET_URL` = URL бэкенда из Railway
- ✅ Домен `astrotop.pro` (уже настроен)

**Где:** https://vercel.com/dashboard → ваш проект → Settings

**Зачем:** Чтобы сайт знал, куда отправлять запросы (на бэкенд)

---

## 🎯 Что нужно сделать:

### Шаг 1: Настроить Railway (БЭКЕНД)

1. Зайдите на https://railway.app
2. Откройте ваш проект
3. **Settings → Build & Deploy Settings:**
   - Root Directory: `server`
   - Start Command: `npm start`
4. **Settings → Networking:**
   - Скопируйте URL (например: `https://xxx.up.railway.app`)

**Это настройка СЕРВЕРА (бэкенда).**

---

### Шаг 2: Настроить Vercel (ФРОНТЕНД)

1. Зайдите на https://vercel.com/dashboard
2. Откройте проект `astrotop.pro`
3. **Settings → Environment Variables:**
   - Добавьте `VITE_API_URL` = URL из Railway
   - Добавьте `VITE_SOCKET_URL` = URL из Railway
4. **Deployments → Redeploy** (пересобрать проект)

**Это настройка САЙТА (фронтенда).**

---

## ⚠️ Важно понимать:

### ❌ НЕПРАВИЛЬНО:
- "У меня сайт на Railway" → Нет, сайт на Vercel!
- "Нужно настраивать astrotop.pro" → astrotop.pro это просто домен, настраивать нужно в Vercel

### ✅ ПРАВИЛЬНО:
- **Railway** = бэкенд (сервер) - настраиваем там настройки сервера
- **Vercel** = фронтенд (сайт) - настраиваем там настройки сайта
- **astrotop.pro** = просто домен (указывает на Vercel)

---

| **Фронтенд** | Vercel | Переменные окружения (VITE_API_URL, VITE_SOCKET_URL) |
| **Домен** | Vercel | Уже настроен (astrotop.pro) |

3. **Настройки Railway** = как работает кухня
4. **Настройки Vercel** = как зал общается с кухней
